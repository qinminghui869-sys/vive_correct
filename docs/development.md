# 开发说明

## 数据流与模块

主路径为：选帧 → 人工选择 → 版本化依据包 → 共用修正 Parquet → RRD 或显式覆盖。同一位姿变换只实现一次，公共逻辑不放入历史兼容入口。

- `run_dataset.py`、`dataset.py`、`cv_features.py`：命令调度、样本发现、选帧与发布。
- `estimate/`、`batch/`：检测、几何、候选选择、模型复核与交付。
- `human_review.py`、`review_exclusions.py`、`axis_calibration.py`、`review_bundle.py`：人工记录、共享轴向计算、依据包与完整性校验。
- `review_server.py`、`review_ui/`：HTTP 接口、后台任务与浏览器交互。
- `review_catalog.py`、`feature_progress.py`：稳定编号与选帧进度；`task_locks.py`、`runtime_cache.py`：跨进程任务锁与进程内缓存。
- `review_actions.py`、`review_repair.py`：重建、导出和历史兼容；`parquet_correction.py`：字段保真的刚性变换。
- `source_data.py`、`review_io.py`：原始备份、源文件事务、输出锁与 JSON 原子写入。
- `rerun_export.py`、`ego_data/`：录制编排、同步和渲染；深度元数据统一由 `ego_data/depth_metadata.py` 解析。

计算公式见 [校准模型](hand_pipeline.md)，API 与 schema 见 [字段与接口](observations_schema.md)。检测与模型默认参数维护在 `vive_correct/config/*.yaml`；审核并发与缓存默认值维护在 `review_server.py`。显式 CLI 参数优先。

## 必须保持的约束

### 发布与并发

- 同一输出目录只有一个选帧写入进程。先保存图片、候选池，再原子发布 `features.json`；已进入人工审核的结果不可自动覆盖。
- 数据编号持久化且只追加。浏览器每秒轮询轻量状态，列表版本变化时更新列表；新增结果不覆盖当前草稿。
- 审核与导出队列独立，排队即取得跨进程单条任务锁。中断任务仅恢复状态，不自动重提；版本冲突必须拒绝。
- 审核服务的原帧、PNG、深度帧及掩码、相机和姿态共用有界 LRU（`--cache-mib` 可调），键绑定文件身份、大小及高精度时间戳。相同键的并发缺失合并计算，失败后可重试，大数组复制在锁外完成。
- 预览与图像编码分别限流，缓存命中不占计算槽位。角度变化复用几何；四角、帧、源数据或外参变化使几何缓存失效。前端取消旧预览并校验数据、手侧、帧号及编辑版本。
- 静态汇总页最多每秒刷新，结束时强制刷新。记录扫描、任务排队与执行、文件修正、RRD 渲染耗时；性能对比使用同一输入和参数，不降低检测或录制质量。

并发参数与默认值统一见 [操作指南](review_rebuild.md#并发与响应)。

### 校验与写入

- 打开数据、通过审核、导出和重建执行必要的完整校验，缓存不能替代依据校验。输入、审核、标定或计算代码变化使旧依据失效。
- 整条排除以输出根目录的 `rejected_episodes.json` 为准，服务端保存、通过、导出和重建必须执行拦截；记录按样本路径去重，写入持有单条任务锁及根索引锁。缺失图像或几何不能阻止拒绝操作。
- 预览只读；审核重新计算，不信任客户端投影。缺失姿态不使用单位旋转代替。
- 审核和导出仅写输出目录；只有 `rebuild --in-place` 覆盖六个源文件。初始备份不覆盖，重复重建使用原始基线。
- 长操作持有单条输出锁，根锁只用于索引更新。读源数据用共享锁，覆盖和恢复用排他锁；同时需要两类锁时，先取输出锁，再取源锁。
- 六文件先生成、校验，再备份、登记、替换、校验和提交；全部成功才发布。失败或中断恢复到本次执行前版本。
- JSON 不允许 NaN，事务登记需同步文件和目录。新增 `meta/` 写入必须纳入同一事务。

## 检查与验证

需要 Python 3.10+、Node.js 和开发依赖：

```bash
python3 -m pip install -r requirements-dev.txt
bash scripts/check.sh
```

脚本执行 Ruff、前端语法检查及两组单元测试，CI 使用同一入口；无需真实数据或模型密钥，HTTP 测试需允许绑定本机临时端口。修改 Python 后格式化相应文件；前端格式使用 Prettier 3.6.2：

```bash
python3 -m ruff format path/to/changed.py
npx --yes prettier@3.6.2 --write vive_correct/review_ui
```

新增测试应覆盖可观察行为：不同参考帧与同步边界、旋转与骨长、字段保真、动态发布、独立队列、缓存失效、版本冲突、重复重建及失败恢复。涉及交互时补充浏览器“调整—暂存—重载—审核—手动导出”验证；记录样本、参数、输入与代码版本，区分功能通过和精度验收。
